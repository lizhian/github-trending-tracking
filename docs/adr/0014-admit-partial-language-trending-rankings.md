# 分语言日榜部分成功时先提交候选

任一语言网页失败或超出本次发现预算时，用成功榜单先合并排序、提交前 100 名；这样即使某个语言长期失败，其他语言仍能持续提供候选。每个发现时段保存成功的语言页和已提交仓库，补抓只请求未成功的页，并补交新进入前 100 名的候选。已经提交的候选继续按普通规则准入、观测和淘汰，因此同一时段累计提交可能超过 100。

进入下一个 12 小时时段时丢弃旧时段的未完成抓取进度，不撤回已提交的候选。只有全部语言成功才刷新来源的最近成功时间。榜单今日 Star 只参与候选排序，不写入本站快照。决策记录见 [#51](https://github.com/lizhian/github-trending-tracking/issues/51)。
