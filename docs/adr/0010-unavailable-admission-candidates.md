# 公开不可访问的候选结束本次收录

2026-10-29，Linux.do 趋势源发现的 `AnkioTomas/qqpet` 已被作者删除，普通候选仍无限重试并持续触发页面异常提示。用户已确认：带 Token 查询找不到仓库、匿名请求也返回 404 时，自动将该候选移出待重试队列；网络超时、限流、403 和 5xx 继续重试。该结果表示仓库公开不可访问，不能据此断言仓库已删除。

此次范围仅限尚未收录的候选，已收录追踪项目及其 Star 历史沿用现有规则。本决策为 ADR-0009 的“普通采集无次数上限”增加明确不可访问的例外。

用户进一步确认：同一轮完成带 Token 查询及匿名 404 复核，即可结束本次候选收录，无需跨轮累计失败次数。公开不可访问的结果缓存 24 小时，趋势源在缓存期间再次发现同一地址时直接跳过；缓存到期本身不触发检查，仅在趋势源再次发现时重新检查。

明确结束的候选不再计入“后台将重试”的异常，移出队列时同时更新对应收录状态；同批其他候选仍有真实失败时保留异常提示，不能通过清空全部失败状态隐藏其他问题。

用户已确认：主动投稿绕过本决策新增的不可访问缓存，立即请求 GitHub 重新检查，沿用现有投稿频率限制。确认仓库可访问后清除该地址的不可访问缓存并继续正常收录；Linux.do README 资格缓存仍遵守 ADR-0007/0008，不受此例外影响。

用户已确认整体方案并授权实施，开发任务为 [#35](https://github.com/lizhian/github-trending-tracking/issues/35)。
