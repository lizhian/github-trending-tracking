# 移除最近上榜，以观测增长和项目规模决定同分淘汰顺序

2026-10-29，用户确认不再需要“最近上榜”功能，删除其展示、接口、存储和发现时间刷新逻辑，减少无用数据维护。此决定替代 ADR-0004 的最近上榜刷新规则及 ADR-0008 的尚未上榜语义；趋势源发现、投稿、去重、重试及追踪周期规则继续有效。

淘汰候选依次按保留评分、24 小时 Star 净增量、Star 总数、本次入库时间升序排列，最后按项目 ID 稳定排序；保护期及可靠观测条件继续有效。删除数据库列采用离线迁移，保留项目身份、追踪周期、入库时间和全部 Star 快照；旧备份仍可验证、恢复后升级，旧镜像不能直接读取迁移后的库。
